Pokémon character art: Nintendo / Game Freak / The Pokémon Company, via the above public decompilation projects and their contributors.
The original downloaded images are retained unchanged. The game treats palette entry zero as transparent while drawing, as the source games do.
The route animation alternates the two movement poses and adds a one-pixel hop. The town pose is static. No network request is made at runtime; both images are embedded in each release.
